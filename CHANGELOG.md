### Допоміжні рішення та додаткові модифікації
- Скрипт автоматичного перевизначення шрифтів при виборі української локалізації.
- Перевизначення початкового меню вибору мови, для додавання опції "українська".
- Перевизначення меню налаштувань для додавання опції "українська"; також виправлення відображення блоку мови та додавання повзунка розміру швидкого меню для андроїд.
- Механізм підміни рядків «на льоту» з умовами, що дозволяє застосовувати переклад до недоступних для перекладу стандартними засобами renpy рядків.
- Механізм введення різних відмінків імені.
- Скрипт для зміни розміру швидкого меню на андроїд.
- Додавання оверлеїв команди перекладу на головне меню.
- Виправлення екрану завдання "Need of a Trainer" — одна з частин була технічно тяжка для перекладу, тому блок завдання перевизначено.
