### 🔍 Структура файлів гри
Більшість файлів перекладу розподілено за зрозумілою логікою:
* `script.rpy` — **основна сюжетна лінія** гри.
* `*_events.rpy` — персональні сцени та діалоги з відповідними героїнями.
* `common.rpy`, `screens.rpy` — системний інтерфейс рушія Ren'Py та головне меню гри.
* `map_*.rpy`, `rpg_battle.rpy`, `quest.rpy` — мапа світу, квести та бойова система, предмети тощо.

<details>
<summary><b>Повний перелік призначення файлів (натисніть, щоб розгорнути)</b></summary>

* `Xmas_event.rpy` / `halloween_events.rpy` — сезонні святкові події у крамниці Томое.
* `bath_events.rpy` / `beach_events.rpy` / `tea_events.rpy` — тематичні події (купальня, пляж, чаювання).
* `blacksmith_store.rpy` / `magic_store.rpy` — крамниці спорядження та магії.
* `cleaning_events.rpy` / `yeahwood.rpy` / `yeahfish.rpy` — активності (лісоповал, розчищення, риболовля).
* `definitions.rpy` / `gallery.rpy` — імена персонажів.
* `pa_gal.rpy` — додаткові сцени для підписників Patreon (⚠️переклад під питанням).
* `tablon_task.rpy` — завдання з дошки оголошень.
* `god_world.rpy` / `kingdom_events.rpy` / `lycoris_clan.rpy` — окремі сюжетні арки та локації пізньої гри.
* `updater_screen.rpy` / `devlog_text.rpy` — екран оновлення гри та девлог.
* `day_time.rpy` / `menus.rpy` — підказки до персонажів, різні елементи загального внутрішнього інтерфейсу гри.

## 🚀 Встановлення та оновлення (Windows/Linux)
> [!NOTE]
> Встановлення або видалення локалізації **не пошкодить** ваші файли збережень (saves).
>
> Встановлюючи мод наведеним нижче чином, ви встановлюєте тестову збірку, що:
> * є незавершеною;
> * може містити текстові помилки;
> * може спричинити помилки у роботі гри.

1. Завантажте архів перекладу: натисніть зелену кнопку **`Code` ➜ `Download ZIP`** вгорі репозиторію.
2. Розпакуйте теку `game` з архіву в теку гри з заміною файлів:
   * **Якщо є папка `base/`:** розпакуйте всередину `base/`.
   * **Якщо папки `base/` немає:** розпакуйте в корінь поруч із `Goddesses'_Whim.exe`.
3. Запустіть гру:
   * При першому старті виберіть **Українська** у списку мов.
   * Якщо гра вже була запущена: відкрийте **Options ➜ Language** і перемкніться на українську.

> **Для оновлення перекладу:** обов'язково видаліть попередню версію перекладу (інакше можливі проблеми), завантажте і розпакуйте нову версію.

## 📱 Запуск на Android (JoiPlay)
Офіційний готовий `.apk` не збирається, проте гра з модом працює через емулятор [JoiPlay](https://joiplay.net/):
1. Встановіть **JoiPlay** (1.21+) та додаток **Ren'Py Plugin** (8.5.0+).
2. Розпакуйте ПК-версією гри та мод відповідно у пам'ять телефона.
3. Додайте гру в JoiPlay, вказавши шлях до виконавчого файлу `.py` або `.exe`.

### 🪄 Додаткові вбудовані патчі для Android:
* Виправлено перенесення блоку вибору мови на малих екранах.
* Додано повзунок у налаштуваннях для регулювання розміру кнопок швидкого меню.

## ❌ Видалення
Перейдіть до робочої теки гри (у теку `base/`, якщо вона є, або безпосередньо в корінь) і видаліть каталог перекладу:
```text
game\tl\ukrainian\
```
